# FAQ

## What problem does SafeChange solve?

It answers a simple production question:
**can this change land safely, and can it be rolled back cleanly if verification fails?**

## Is this only for CI?

No. It can run locally or in CI.

## What does the system return?

Human-facing outcomes are:

- **SAFE**
- **REVERTED**
- **BLOCKED**

The underlying receipt and audit path preserve the exact record.

## Is this a monitoring tool?

No. It is a boundary layer for risky change application.

## What is the fastest way to evaluate it?

Install the Community Edition and run the example in [QUICKSTART.md](QUICKSTART.md).  
If you already have a real risky path, use the paid pilot path instead.

## How do pilots work?

See [PILOT.md](PILOT.md). The pilot stays narrow:
one risky path, one support window, one success review.
