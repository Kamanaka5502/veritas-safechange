# Paid Pilot

## Best fit

Use a paid pilot when you have **one risky state change or deploy path** that needs a harder answer than “the pipeline passed.”

Good examples:
- config promotion with rollback risk
- schema/version steps with verification gates
- release steps that must revert safely under failed checks

## Pilot shape

- one bounded workflow
- one support window
- one success criterion set
- one conversion decision at the end

**One path. One boundary. One proof trail.**

## Commercial seriousness

Typical pilot engagements start at **USD 7,500** for one defined path.  
Larger or more integration-heavy pilots are scoped separately.

## What a pilot includes

- installation help
- one workflow setup
- bounded support during the pilot window
- audit / replay verification help
- success review and conversion recommendation

## What a pilot should prove

At the end of the pilot, the team can answer:

- did the path stay **SAFE** when expected
- did the system **REVERT** cleanly when verification failed
- did receipts and replay hold cleanly
- should this move into a broader commercial deployment

## What a pilot is not

- not a broad platform rewrite
- not unlimited consulting
- not an open-ended support relationship
